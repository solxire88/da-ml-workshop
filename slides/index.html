What is a model?

A model is a function close to the points

Points = past examples.

A first guess is far from the points. Big errors.

Training moves the function until it is close to the points.

y = f(x)

x = what we know about an order
y = what we want to predict

A good model

It must generalize

Memorizes the points

Learns the pattern

New points arrive (orders the model has never seen).

A good model generalizes: new points land close to it.

That is why we keep a test set: new points to check the model.

The idea

A model is only as good as its data

Evaluation metrics

How do we measure "good"?

Accuracy

How many answers are right?

Misleading when one answer is rare.

Precision

When I say returned, am I right?

Good when false alarms are costly. Example: a spam filter.

Recall

How many real returns did I catch?

Good when missing one is costly. Example: detecting an illness.

F1

One number that balances precision and recall.

Good when both matter.

Different problems need different metrics.

For us, every returned parcel we miss costs money. We choose recall.

from sklearn.metrics import accuracy_score, precision_score, f1_score, recall_score
